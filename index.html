PROJECT TEMPORARILY SHUT DOWN

Development Has Frozen.

After careful consideration, I've decided to stop development of the Ice Scream 3 × 4 Ultimate Community Project for now.

This is not necessarily goodbye forever. The project is entering an indefinite break.

❄ Why Did We Shut Down?

  • Development became more difficult than expected.
  • Technical issues slowed down progress.
  • Creating and testing modifications takes time.
  • A break and more time for other things are needed.

📁 What Happens Now?

  • No new APK releases are planned.
  • No new features are currently being developed.
  • This website will remain as a project archive.
  • Previous progress and announcements may remain available.

🌨 Will We Return?

Maybe someday...

If motivation, time, and the right conditions come together, this project could return in the future.

There is no confirmed return date.

Not the End. Just a Long Winter.

❄ ❄ ❄

Thank you to everyone who supported this unofficial fan project and followed its journey.
